# Git Conventions

- **Commits**: conventional (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`); explain _why_, not just what.
- **Branches**: prefix with `feature/`, `fix/`, or `hotfix/` (e.g. `feature/user-auth`, `fix/login-validation`).
- **Pull requests**: keep <400 lines when possible; include description and testing notes; link related issues. Never force-push `main`/`master`.
- **No AI attribution**: never indicate AI assistance in commits, PRs, branches, labels, or comments (no `Co-Authored-By`, no "Generated with Claude Code", no "🤖" footer). Write as if the human authored it directly; omit attribution lines from any template or skill.
- **No em dashes in human-facing text** (commits, PRs, issues, emails, chat, release notes); use a period, comma, colon, or parentheses. Does not apply to these rules files.
